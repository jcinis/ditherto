03 / PUT IT TO WORK

A small tool.
Room for your workflow.

Use it in a page, a build script, or an agent’s render–inspect–adjust loop. Resizing is optional; the responsive helper follows your CSS layout.

Let the page set the size.

import { observeDitherDOM, PALETTES }
  from 'ditherto/dom';

const images = observeDitherDOM('img.dither', {
  palette: PALETTES.MONO_BLUE,
  resample: 'area'
});

// Per-image tuning, shared visual style.
await images.images[0].update({ exposure: 0.3 });
// On unmount: images.destroy();

Place each image in a layout-sized wrapper. Width changes rerender from the original pixels.

Or take it to the terminal.

npx ditherto photo.jpg -o photo.png \
  --palette MONO_BLUE \
  --algorithm atkinson \
  --exposure 0.3 --json

Explicit inputs, reusable settings, PNG output, and JSON for scripts. No width flag? Original dimensions.
