About this comparison

Both algorithms use the same resized source, palette and 4×4 Bayer grid. Knoll searches for multiple candidate colors independently for each pixel, with no error passed to neighboring pixels. Strength zero gives nearest-color quantization. More candidates increase processing time; they do not enlarge the 4×4 pattern.

Times show one browser worker run of the algorithm, excluding image decoding, resizing, palette generation and display. Initial runs may include JavaScript warm-up. This prototype uses encoded sRGB color distances. Knoll is available as a built-in algorithm.

Based on Revisiting Yliluoma’s ordered dither algorithm. All processing stays in your browser.
